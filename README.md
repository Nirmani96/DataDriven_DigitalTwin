# ED Digital Twin (10-Minute Resolution)

A database-driven discrete-event digital twin of an Emergency Department (ED),
forecasting patient arrivals and discharges over a **12-hour horizon** at
**10-minute resolution** using stochastic simulation with 100 replications.

## Overview

This repository contains a complete framework for building, validating, and
statistically comparing a database-driven ED Digital Twin against a conventional
Discrete-Event Simulation (DES) baseline. It uses historical visit data to fit
statistical distributions for arrivals and length-of-stay (LOS), then runs
stochastic forward simulations from a chosen forecast point.

The framework has three components:

**1. Digital Twin (DT)** — the main database-driven model that dynamically
updates its parameters from recent data at each forecast point.

**2. DES Baseline** — a conventional SimPy-based simulation using fixed
pre-fitted parameters, used as a comparison benchmark for the Digital Twin.

**3. Statistical Comparison** — scripts that formally compare DT vs DES
performance using paired statistical tests (Shapiro-Wilk, paired t-test,
Wilcoxon signed-rank).

The framework produces:
- 10-minute resolution forecasts of arrivals and discharges
- 95% confidence intervals across 100 replications
- Validation metrics (MAE, RMSE, MAPE, DTW similarity)
- Plots comparing simulated vs actual patient flow
- Statistical test results comparing DT and DES model performance

## Data

This model was developed and validated using Emergency Department data from
Rambam Hospital, Israel, as published in:

> Armony, M., Israelit, S., Mandelbaum, A., Marmor, Y. N., Tseytlin, Y., &
> Yom-Tov, G. B. (2015). On patient flow in hospitals: A data-based
> queueing-science perspective. *Stochastic Systems*, 5(1), 146–194.
> DOI: [10.1214/14-SSY153](https://doi.org/10.1214/14-SSY153)

The raw `.mdb` database files are **not included** in this repository.
To reproduce results, obtain the dataset from the authors of the above paper
and place the `.mdb` files in the following structure:

```
data/input/<subfolder>/<filename>.mdb
```

Each `.mdb` file must contain a `visits` table with at minimum:

| Column       | Description                        |
|--------------|------------------------------------|
| `entry_date` | Patient arrival datetime           |
| `exit_date`  | Patient departure datetime         |
| `entry_group`| Patient group flag (filter = 1)    |
| `exit_group` | Exit group flag (filter = 1)       |

### Requirements

## How To Run

### Step 1 — Set your forecast date

Open `config.py` and set `FORECAST_DATE` to the datetime you want to forecast from:

```python
from datetime import datetime
FORECAST_DATE = datetime(2007, 9, 20, 12, 0)  # year, month, day, hour, minute
```

---

### Running the Digital Twin

#### Step 2 — Generate LOS parameters

Run `LOS.py` to fit Gaussian Mixture Models to the last 2 weeks of
length-of-stay data. This creates a JSON parameter file used by the simulation:

```bash
python LOS.py
```

Output: `data/input/parameters/los_parameters_weekday_<YYYY-MM>.json`

#### Step 3 — Run the digital twin

```bash
python Digital_Twin_10_minute.py
```

Output saved to: `data/output/<forecast_datetime>/` and `data/plots_12h/<forecast_datetime>/`

---

### Running the DES Baseline

The DES baseline must be run for the **same forecast date** as the Digital Twin
so that the outputs can be compared.

#### Step 4 — Run the arrivals DES baseline

```bash
python arrivals_simulation_validation_12_hours.py
```

Output: `Compare DT and DES/arrivals_<timestamp>.csv`

#### Step 5 — Run the discharges DES baseline

```bash
python discharge_validation_12_hour.py
```

Output: `Compare DT and DES/discharge_<timestamp>.csv`

---

### Running the Statistical Comparison

Before running the comparison scripts, update the file paths at the top
of each script to point to the correct DT output folder and DES CSV for
your chosen forecast date.

#### Step 6 — Compare arrivals performance

```bash
python Compare.py
```

#### Step 7 — Compare discharges performance

```bash
python Compare_Discharge.py
```

Both scripts output:
- Shapiro-Wilk normality test results
- Paired t-test or Wilcoxon signed-rank test result and p-value
- Median ± IQR summary table
- Scatter plots and violin plots (DT vs DES per-replication values)

## Outputs

### Digital Twin outputs

|---|---|---|
| `data/output/<forecast_datetime>/` | `dt_fixed_validation_per_replication_10min.csv` | Per-replication MAE, RMSE, MAPE, sMAPE, DTW |

|---|---|---|

Both `Compare.py` and `Compare_Discharge.py` print results to the console and
display the following plots interactively:
- Scatter plot: DT vs DES per-replication metric values (with identity line)
- Violin plot: Distribution shape comparison (DT vs DES)

## Key Parameters

These can be adjusted at the top of `Digital_Twin_10_minute.py`:

| Parameter | Default | Description |
|---|---|---|
| `NUM_RUNS` | 100 | Number of simulation replications |
| `FORECAST_HOURS` | 12 | Forecast horizon in hours |
| `ED_PROBABILITY` | 0.675 | Probability a patient enters the ED pathway |
| `STEP_MINUTES` | 10 | Time resolution of the simulation |
